Guide to Getting Your Gemini API Key

This guide will show you how to get a free API key from Google AI Studio to enable the "Organize Chats with AI" feature in the Gemini Chat Folders extension.

FAQ: Privacy & How it Works

Before proceeding, it's important to understand how your data is handled:

  • Why an API Key? The extension needs to communicate with Google's AI to suggest folder structures. Using your own free key allows the extension to make a direct connection from your browser to Google, bypassing any third-party servers.
  • What data is sent? ONLY the titles of your unorganized chats and the names of your existing folders. The extension never accesses, reads, or transmits the contents/messages of your conversations.
  • Where is the key stored? The key is saved locally in your browser using Chrome's native and secure sync storage (chrome.storage.sync). It is never shared with the developer.
  • How does the AI feature work? 1) The extension lists your uncategorized chats. 2) You select which ones to process. 3) The AI analyzes the titles and suggests a folder tree. 4) You review a visual preview and must manually approve the changes before they are applied.

Step 1: Go to Google AI Studio

First, visit the official Google AI Studio page for managing API keys. You may be asked to sign in with your Google account.

Go to Google AI Studio

Step 2: Create the API Key

Once on the page, the process is very straightforward.

  1. Look for and click the "Create API key" button.
  2. In the window that appears, Google will ask you to create a new Cloud project. This is normal and necessary. Simply click the "Create API key in new project" button.

Step 3: Copy Your New Key

Congratulations! Your API key has been generated. Now you just need to copy it.

  1. The key will appear in a list. It's a long string of text and numbers.
  2. Click the copy icon (it usually looks like two overlapping squares) next to the key string to copy it to your clipboard.

Warning: Treat this key like a password. Do not share it publicly.

Step 4: Enter the Key in the Extension

Now, return to the Gemini page and open the extension's settings.

  1. In the Gemini interface, click the three-dot menu in the "Folders" panel and select "Settings".
  2. In the API tab, paste the key you just copied into the Gemini API Key field.
  3. Click "Save and Verify". If everything is correct, you will see a confirmation message.

You're all set! You can now use the powerful AI organization feature for your chats.

恭喜！您的 API 金鑰已成功發行，現在只需將其複製：

  1. 清單中將顯示一串由英文與數字組成的金鑰字串。
  2. 點擊金鑰旁邊的複製圖示（兩個重疊的方框符號），複製至剪貼簿中。

安全警告： 請將此金鑰視同密碼妥善保管，切勿公開分享。

第四步：於擴充功能設定中輸入金鑰

現在返回 Gemini 頁面，開啟擴充功能設定：

  1. 在 Gemini 介面中，點選「Folders」面板右上角的三個點選單，選擇 「設定」。
  2. 切換至 API 分頁，在 Gemini API 金鑰 欄位貼上剛才複製的金鑰。
  3. 點選 「儲存並驗證」。若連線成功，系統會顯示綠色確認訊息。

設定全部完成！您現在可以立即體驗強大的 AI 自動分類與對話整理功能了。
